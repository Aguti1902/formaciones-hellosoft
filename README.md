# formaciones-hellosoft

Plataforma de formación en vídeo de Hello Soft (Hello Nails): tutoriales para franquiciados y para tienda.

## Cómo arrancarla

```bash
npm install
npm run dev
```

Abre [http://localhost:5173/](http://localhost:5173/).

## Acceso

- Franquiciados: `FranquiciaHello26`
- Tienda: `TiendaHello26`

Las contraseñas se pueden cambiar en `src/credentials.js`.
Las dudas enviadas se guardan en `preguntas.json` (no se sube al repositorio).
